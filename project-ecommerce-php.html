Contexte & Objectifs

Attendu : E-commerce complet avec architecture MVC, parcours d'achat fluide et admin CRUD fonctionnel.

Objectif : Livrer un parcours utilisateur stable (catalogue → panier → commande → historique) avec état applicatif fiable.

Contraintes : MVC imposé, base SQL, gestion d'état (sessions/cookies), cohérence UX.

Authentification : Hash robuste (sel/poivre) mis en place au niveau équipe.

Durée : 1 mois et demi (octobre-novembre 2024)

Équipe : 3 personnes

Accéder au site live →

Mon Rôle

  • Panier : Développement complet (ajout/suppression/quantités, calcul total, persistance session)
  • Commandes & historique : Validation panier→commande (stockage base SQL), page historique par utilisateur (tri descendant), affichage n°/date/produit/prix, logique anti-doublons
  • État applicatif : Persistance panier/commandes/préférences via sessions PHP et cookies
  • UX théme sombre : Feedback visuel sur ajout panier, validation commande, erreurs ; lisibilité optimisée
  • Intégration : Parcours complet produit → panier → commande → historique → admin

Fonctionnalités Clés

  • Catalogue produits + fiche détaillée
  • Panier persistant (ajout/suppression/quantités)
  • Validation commande (transformation panier → base SQL)
  • Historique commandes (par utilisateur connecté, tri descendant)
  • Admin CRUD produits
  • Authentification utilisateur

Qualité Technique

Architecture MVC : Contrôleur frontal avec routage par paramètres (action/controleur), séparation modèle/vue/contrôleur.

Persistance & état : Panier en session, commandes/historique en base SQL. Séparation claire panier actif vs commandes validées, historique unique par compte.

Données : CRUD produits, requêtes structurées, logique anti-doublons sur validation commande.

UX : Feedback visuel (ajout/validation/erreurs), thème sombre cohérent, lisibilité optimisée.

Méthodes de travail

Développement itératif : Tests manuels après chaque fonctionnalité (panier → commande → historique), ajustements UI en continu selon feedback utilisateur.

Versioning Git : Collaboration en équipe de 3 via branches feature, commits atomiques, merge après validation.

Debugging : Logs PHP + inspection SQL (phpMyAdmin) pour valider persistance commandes et cohérence panier/historique.
