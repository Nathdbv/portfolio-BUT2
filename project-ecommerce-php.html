Projets / Projet IUT · oct.–nov. 2025

E-commerce PHP.

Catalogue → panier persistant → commande → historique → administration. Architecture MVC en PHP/SQL.

Équipe
3 personnes
Durée
1 mois et demi
Rôle
Dev full-stack
Note
17,25 / 20

Contexte

Attendu : un e-commerce complet avec architecture MVC, un parcours d'achat fluide et une administration CRUD fonctionnelle.

Contraintes : MVC imposé, base SQL, gestion d'état par sessions et cookies, cohérence de l'expérience utilisateur.

Mon rôle

  • Panier : ajout, suppression, quantités, calcul du total, persistance en session.
  • Commandes et historique : transformation panier → commande en base SQL, historique par utilisateur (tri descendant : n°, date, produit, prix), logique anti-doublons.
  • État applicatif : persistance du panier, des commandes et des préférences via sessions PHP et cookies.
  • Interface sombre : retours visuels sur l'ajout au panier, la validation et les erreurs.

Technique

MVC : contrôleur frontal avec routage par paramètres (action / contrôleur), séparation modèle / vue / contrôleur.

Données : panier en session, commandes en base ; CRUD produits ; requêtes préparées PDO.

Sécurité : hachage des mots de passe avec sel et poivre, mis en place au niveau de l'équipe.

Méthode

Tests manuels après chaque fonctionnalité (panier → commande → historique). Git en équipe de 3 avec branches de fonctionnalité et commits atomiques. Débogage par logs PHP et inspection SQL dans phpMyAdmin.

Compétences

C1 Réaliser
Logique métier (panier, commandes, historique), architecture MVC, contrôleur frontal
C4 Gérer
CRUD produits, structuration de la base, requêtes SQL
C6 Collaborer
Versioning Git, travail en équipe
