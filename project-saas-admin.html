Le Positionnement

La plupart des petites structures ont besoin de mettre à jour rapidement leur site (horaires, visibilité, informations légales) mais ne disposent ni d'une équipe technique ni d'un processus fiable pour le faire sans risquer de rendre le site inopérant.

Le produit ne se limite pas à une fiche établissement. Il intègre aussi un concepteur de site modulaire permettant d’éditer le contenu, d’organiser les sections par blocs, de prévisualiser le rendu et de faire évoluer la vitrine sans intervention technique.

L'Usage Produit (Multi-tenant)

L'outil réunit dans une interface centralisée la composition du site, la gestion des données métier et la gouvernance de publication :

  • Concepteur de site : Édition modulaire par blocs et preview (visualisation avant validation).
  • Workflow conditionné : Le propriétaire (Owner) publie directement. Le Manager/Staff propose, l'Owner valide.
  • Multi-tenant : Gestion de plusieurs restaurants par d'un même compte, avec application stricte de quotas.

Architecture Cloud Edge

L'infrastructure entière est distribuée sur l'écosystème Cloudflare, garantissant l'absence de gestion de serveurs lourds, une sécurité par conception (Security by Design), et des performances globales.

  • Découplage Front / Back : Front Admin React propulsé sur Cloudflare Pages. Hub SSR dédié pour le rendu public.
  • Zero Trust Relatif : Le Front n'accède jamais au Worker responsable de la logique métier publiquement. Tout passe par un Proxy applicatif (Pages Functions /api/...).
  • RBAC Strict & Cryptographique : Rôles owner, manager et staff imposés serveur avec token gates pour bloquer l'accès aux Previews.
  • Audits Sécurisés : Traçabilité complète des actions du workflow sans stockage des IPs brutes pour rester conforme au RGPD.

Ce Que Ce Projet Prouve

Bien plus qu'une simple maquette front-end, ce projet confirme ma capacité à piloter des systèmes complexes orientés Product Engineering :

  • Capacité produit complète : Construire un Admin SaaS complet intégrant un véritable builder de contenu.
  • Spectre technique large : Gérer simultanément l'édition (blocs/preview), la structure, la publication et la sécurité.
  • Usage métier ciblé : Penser un outil pour un usage quotidien critique ("Control Plane"), et pas uniquement pour une interface marketing.
