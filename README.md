# portfolio-BUT2

Portfolio de Nathan Dabonneville — BUT Informatique, parcours IAMSI, IUT Montpellier-Sète.
Site statique (HTML/CSS/JS, sans build), servi par GitHub Pages.

- `style.css` — direction graphique « Rythme ».
- `rythme.js` — calcule chaque jour si je suis à l'IUT ou à la Mutuelle des Motards,
  d'après le calendrier d'alternance officiel (prévisionnel) et le contrat du 1er sept. 2026 au 31 août 2027.
  Pour simuler une date : `index.html?date=2027-03-01`.
- `work.html`, `apprentissage.html`, `project-saas-admin.html` — redirections des anciennes adresses.
